# Hero image drop-in

Place the guard photo here as **`hero.jpg`** (or `.png` / `.webp` — update the
path if you change the extension).

- Referenced from: `client/src/styles/sections.css` → `.hero__visual`
- Served at: `/hero/hero.jpg`
- Recommended: at least 1200 x 1500px, portrait or square crop. The subject
  sits on the right of the frame, so leave headroom on the left where the red
  diagonal wedge overlaps.

Until the file exists the hero panel falls back to a clean dark gradient, so
the site looks finished either way.
